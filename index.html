What this tool checks

Dimensions are read from supported file headers. JPEG, PNG, and WebP files receive a limited scan for EXIF, XMP, IPTC, and text metadata markers. Other formats show metadata status as unknown. This tool does not decode image pixels, read EXIF field values, or modify files.
